# E-Commerce QA Automation Portfolio

## Project Overview

This project demonstrates practical software quality assurance skills through testing an e-commerce application. It includes manual test planning, test case design, test execution, defect documentation, and progressively developed API and UI automation.

**Application Under Test:** [Automation Exercise](https://automationexercise.com/)

**Project Status:** In Progress

## Objectives

- Understand and apply software testing principles.
- Design clear, reproducible test cases.
- Execute tests and compare actual results against expected results.
- Identify, investigate, and document reproducible defects.
- Build API automation using Python and pytest.
- Build UI automation using Playwright.
- Integrate automated tests into a GitHub Actions workflow.

## Current Scope

The initial manual testing covers:

- Product search
- Product category filtering
- Product details
- Shopping cart operations
- Adding and removing products

## Work Completed

- Created the initial test plan.
- Documented test scenarios and detailed test cases.
- Executed initial tests for product search, category filtering, and cart removal.
- Recorded the reported execution results.
- Created and published the project repository on GitHub.

## Test Reporting

Test cases are recorded with their preconditions, test data, steps, expected results, actual results, and execution status.

Only reproducible and evidence-supported issues will be documented as defects. Features that have not been tested will not be reported as passing.

## Scope Limitations

This project uses a publicly accessible practice application. Testing is limited to available functionality and does not include real payment processing, unauthorized security testing, or load testing against the live website.

Application behaviour and availability may change over time.

## Planned Improvements
