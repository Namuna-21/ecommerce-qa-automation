# E-Commerce Application — Test Plan

## 1. Project Overview

Project Name: E-Commerce QA Automation Portfolio

Application Under Test: Automation Exercise
Website: https://automationexercise.com/

Testing Type: Manual Testing, API Testing, UI Automation

## 2. Test Objectives

- Verify product search functionality.
- Verify product category filtering.
- Verify product details display.
- Verify shopping cart operations.
- Identify, document, and report reproducible defects.

## 3. Scope of Testing

### In Scope

- Product search
- Category filtering
- Product details
- Add to cart
- Remove from cart
- Quantity handling

### Out of Scope

- Real payment processing
- Production load testing
- Security penetration testing

## 4. Test Approach

- Explore the application manually.
- Design and execute test cases.
- Record actual and expected results.
- Report reproducible defects with evidence.
- Add API tests using Postman.
- Automate selected API and UI tests using Python.

## 5. Test Environment

Operating System: Windows 11
Browser: Google Chrome
Editor: Visual Studio Code
Version Control: Git and GitHub

## 6. Entry Criteria

- The application is accessible.
- The required feature is available.
- Suitable test data can be identified.

## 7. Exit Criteria

- Planned test cases have been executed or their status documented.
- Results and reproducible defects have been recorded.
- Known limitations and unresolved issues are documented.

## 8. Risks and Limitations

- The live test website may be unavailable.
- Website behaviour may change over time.
- Backend data and application configuration may not be accessible.
- Results may be affected by third-party or network issues.

## 9. Test Deliverables

- Test plan
- Test scenarios and test cases
- Test execution results
- Defect reports
- Postman collection
- Automated test scripts
- Test execution report
